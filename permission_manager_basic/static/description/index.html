What You Can Control

A detailed view of the access areas covered by the module.

Users, Groups & Companies

  • Assign a policy directly to specific users.
  • Apply the same policy to Odoo user groups for easier team-based administration.
  • Use user and group assignment together when a policy needs mixed coverage.
  • Apply restrictions regardless of company or limit them to selected companies.
  • Activate or deactivate policies without deleting the configuration.

Model Operations

  • Restrict Read, Create, Edit and Delete operations per model.
  • Control Archive, Unarchive and Duplicate actions.
  • Block Import or Export for selected models.
  • Hide a model from the assigned policy when the user should not access it.
  • Restrict selected reports, actions and views associated with the model.

Fields & Conditional UI

  • Hide individual fields from users covered by the policy.
  • Make fields Read-Only or Required.
  • Prevent selected fields from being imported or exported.
  • Apply field state behavior according to configured record conditions.
  • Hide selected buttons and notebook tabs, including conditional button/tab rules.

Records, Menus & Navigation

  • Hide menus and submenus that are not relevant to the assigned users.
  • Use domain-based rules to scope which records are visible through the policy.
  • Keep the interface cleaner by removing unnecessary navigation and controls.
  • Use smart buttons to open configured restriction lines quickly.
  • Use search filters and group-by options to find policies and configured rules faster.

Chatter & Collaboration

  • Control Send Message and Log Note availability.
  • Restrict Activities and message search.
  • Hide attachments and follower controls when required.
  • Control Follow / Unfollow access.
  • Hide the chatter completely for policies that require a minimal record interface.

Global Security & Export Protection

  • Force a policy into Read-Only mode when broad editing should be disabled.
  • Block Debug / Developer Mode for assigned users.
  • Block user login when access must be suspended through policy configuration.
  • Hide the Available Fields area in the Export dialog.
  • Combine model-level Export blocking with field-level No Export rules for more precise control.
