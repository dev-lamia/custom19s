Purchase Requisition

Controlled procurement workflow for Odoo 19

Purchase Requisition provides company-aware approvals, document-level RFQ/PO linking, controlled reset and cancellation workflows, Office Supply and Sale Order integration, and native Odoo Alternative RFQ compatibility. PR-line traceability and quantity matching are intentionally not used.

  • Normal workflow: Manager → SCM → Finance → Issue PO.
  • Sale Order workflow: Manager → SCM → Finance → Confirm Sale Order → Issue PO.
  • Office Supply workflow: Finance → Issue PO.
  • Attach Existing RFQ preserves all current RFQ lines and appends the selected PR material lines.
  • Multiple PRs can be linked to one RFQ at document level.
  • Chatter-based audit trail and controlled reset/cancellation handling.
